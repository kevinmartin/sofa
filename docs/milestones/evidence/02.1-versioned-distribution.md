## Implemented behavior and decisions

Implementation is on `codex/milestone-02.1-distribution` in the isolated milestone worktree, based on owner-approved planning merge `41cb5ef`.

- A thin composite setup Action installs both Linux amd64 binaries from an immutable Sofa release, verifies the bundle with GitHub signed release-asset verification, and exports PATH, release_version, and bin_directory. No repository override or maintained checksum allowlist is introduced.
- Each released job selects independently and retains its selection. An explicit exact release version allows handoff; mixed-version jobs are supported within the same major.
- Candidate builds compile both binaries without factory/model/publication secrets and transfer them only within the exact source/invocation. Admission prepares the delivery invocation's binaries once; work consumes them. Standalone lifecycle, Discovery, and review prepare their own candidate invocations.
- Both CLIs report their embedded version and source through --version and the JSON version command. Compatibility fixtures exercise configuration, state ownership/checkpoints, and aggregate counters.
- Release automation remains disabled until the reviewed implementation is merged and the owner completes documented activation. No Sofa release or tag has been created or moved during this work. Stable v1 activation remains Kevin's decision.

# 01.1 — Deterministic end-to-end regression harness

## Outcome

A candidate sofa commit can be tested through admission, execution, verification, recovery, and draft publication without making a real model request. Fast tests run on every sofa PR; a smaller hosted suite calls the candidate's actual reusable workflows from the designated disposable consumer. Failures identify the stage, scenario, run, and violated invariant. A separate zero-prompt compatibility probe checks that the pinned Copilot package still starts. This milestone does not turn the prototype into a release or merge a sofa PR.

Read [the shared contract](README.md), [milestone 01](01-delivery-slice.md), its [observed failure history](evidence/01-delivery-slice.md), [PLAN.md](../../PLAN.md), and [runtime/recovery](../runtime-and-watches.md). Build on the existing Go fake ACP peer, worker `Runner` seam, state fault tests, security canary, and workflow condition test instead of recreating them.

## Prerequisites and authority

Milestone 01 is complete. Kevin has designated `kevinmartin/sofa-disposable` and its private Project as the test tenant, and has authorized sofa agents to create and move disposable test items to Ready, manage their own branches and PRs, and merge disposable setup PRs. That authorization does **not** permit merging `kevinmartin/sofa`, changing its release channel, or deploying downstream consumers. Verify the current repository/Project IDs and available credential **references** before hosted work; never request, log, or copy secret values.

Use the existing disposable repository first. A run needs a fresh issue and attempt identity but ordinarily **does not** need a fresh repository. A trusted test coordinator may need Project item write, Issues write, Actions dispatch/read, and tightly scoped disposable publication permissions. Keep those permissions out of the fake agent, candidate verifier, and ordinary sofa PR jobs. If a separate coordinator credential is missing, finish local checks and a concrete setup proposal, then leave the hosted acceptance pending. No repository-administration or repository-deletion credential is required for this milestone.

The hosted canary runs from a trusted workflow on the disposable default branch and checks out an **exact sofa candidate SHA**. Do not give an unreviewed `pull_request` or `pull_request_target` job a Project or publisher secret, and do not let issue text select a test mode or executable. Keep the consumer's default-branch fixture unchanged while a scenario is active; serialize suites that share its base. GitHub evaluates reusable workflows in the caller's context, including runner and token permissions, so tests only in the sofa repository cannot replace this hosted check. [Reusable-workflow behavior](https://docs.github.com/en/actions/reference/workflows-and-actions/reusing-workflow-configurations)

## Scope

- Add a Go scenario driver and reusable deterministic fixtures around the **existing production boundaries**. Use fake GitHub API responses, a controlled clock, and named fault points. Drive real admission, state, worker, verifier, and publisher code wherever possible. Assert state transitions and external side effects, not merely returned errors. Reuse existing unit and CLI integration tests; expand only the missing cross-stage cases.
- Extract or adapt the fake ACP peer into a test executable that speaks ACP over stdio inside the restricted worker environment. It must deterministically perform an allowed edit through the normal file capability, and support no-change, refusal, structured auth/quota errors, malformed protocol, timeout, and cancellation scenarios. The fake makes no provider request. A Go `Runner` stub remains useful for fast tests, but it does not count as hosted ACP/container evidence.
- Give the hosted test a narrowly constrained, **test-only** way to use that peer while preserving the actual admission, verification, and publication jobs and their artifact contracts. Only agent startup may be substituted. The normal consumer profile must keep the pinned Copilot package and credential path. A test path must require the exact designated repository identity and trusted dispatch, carry an unmistakable `fake-acp` identity in evidence, have no usable provider credential or `copilot-requests: write`, disable network access in the fake worker container, and fail closed rather than falling back to Copilot. Prefer a separate trusted wrapper or build target over a switch available to issues or ordinary consumer configuration. Document any unavoidable difference from the production workflow.
- Extend parsed workflow-contract tests to cover typed inputs, candidate SHA agreement, pinned package/image architecture and digest, permissions, artifact producer/consumer names, job dependencies, and conditions when execution is deliberately skipped. Check package bytes and OCI platform **independently** of the YAML constants; repeating a mistaken pinned hash in a test would not catch the failure from milestone 01. A static check does not claim to reproduce GitHub's scheduler; confirm the skip/recovery path in the hosted suite. GitHub documents that a skipped job can suppress dependent jobs unless their conditions explicitly handle it. [Workflow syntax](https://docs.github.com/en/actions/reference/workflows-and-actions/workflow-syntax)
- Run a bounded hosted matrix in `sofa-disposable`: fake-ACP edit to one draft PR; non-Ready/invalid and completed redelivery with the work job skipped; one accepted-checkpoint cancellation or controlled publication failure followed by successful recovery; and an unexpected existing branch that remains untouched. Reuse the inert-sentinel boundary check. The full combinatorial crash matrix stays deterministic and local; the hosted suite samples the GitHub-specific transitions.
- Provide a trusted Go coordinator that names every resource with a suite/run ID, records the admitted base and candidate SHA, dispatches or observes runs, checks job results plus artifact/ledger/PR identities, and performs bounded retries. It must not mistake a queued or cancelled run for success, reset an attempt's budget, force-push, merge a generated PR, or overwrite an unexpected branch. On success, close/archive only suite-owned disposable items and remove only suite-owned refs with an exact-head check after assertions. Preserve run links and a redacted report. On failure, retain enough evidence for diagnosis and report owned resources needing cleanup; provide a separate bounded cleanup path.
- Add a zero-prompt hosted Copilot package/ACP initialization probe for platform, archive, and startup drift. Keep a **one-real-prompt** compatibility smoke as an explicit, separately budgeted operator or later release check, not part of the model-free regression suite. A fake ACP peer proves orchestration, not subscription or real harness interoperability.

The ordinary sofa PR check runs the fast deterministic suite and workflow-contract checks without secrets. The hosted suite is a trusted, bounded dispatch for a reviewed candidate SHA and can later run against the merged default branch on a schedule. Start with a maximum of eight hosted dispatches and 45 minutes per candidate; exceeding either limit stops the suite for inspection rather than silently expanding it. Do not use a privileged PR event to run candidate code with credentials. GitHub suppresses many workflows caused by `GITHUB_TOKEN` writes; the coordinator must explicitly dispatch or observe the intended follow-on run and test that it occurred. [Triggering workflows](https://docs.github.com/en/actions/how-tos/write-workflows/choose-when-workflows-run/trigger-a-workflow)

## Historical regressions to encode

| Observation from 01 | Regression assertion |
| --- | --- |
| Reusable input rejected a CLI string supplied to a numeric input | Caller and callee types agree; the actual hosted dispatch reaches admission. |
| Copilot archive used an ARM64 digest and the container pin used an ARM64 manifest on AMD64 | Verify expected package digest, image platform, and zero-prompt startup on the hosted runner before any paid smoke. |
| Standalone Copilot binary exited during `initialize`; its checked package entrypoint worked | Probe the exact supported entrypoint; record fixed error categories without raw stderr. |
| Some ACP turns ended without an edit | Fake peer exercises both an actual edit and no-change; no-change never becomes a successful candidate. |
| Ready revision/issue edits and default-branch changes invalidated admission | Freeze and revalidate specification, Ready revision, configuration, and base; denied work starts no fake or real prompt. |
| Cancellation and retained artifacts required exact producer-run and cumulative-budget handling | Inject failures before/after checkpoint acceptance, artifact loss/expiry, and a terminal cancellation; assert provenance and no budget reset. |
| Recovered verification passed but publication skipped after execution skipped | Parse the job condition and prove on GitHub that retained-candidate recovery reaches publication. |
| Pre-existing human branch blocked publication; a later retry could consume the final infrastructure allowance | Assert exact branch head preservation, no PR on conflict, finite retry counters, and successful one-retry recovery only after a controlled test branch is removed. |
| A draft PR could be created before its API response or first lookup was lost | Reconcile the existing PR without a second creation request or replacement branch. |
| Privileged credentials must not reach the worker or evidence | Use inert sentinels, scan the tested mounts/artifacts, and assert separate job permissions and redacted diagnostics. |

## Checkpoints

1. **Scenario inventory and trust design:** map each historical failure to an existing test or a gap. Freeze scenario IDs, fixtures, expected side effects, candidate-SHA binding, coordinator permissions, and a finite hosted run/time budget. Inspect the current disposable setup before requesting any missing credential reference.
2. **Fast deterministic suite:** complete cross-stage Go scenarios, fake ACP process behaviors, fault injection, workflow-contract checks, and a single command suitable for an unprivileged sofa PR check.
3. **Hosted model-free suite:** install the trusted test path in the designated disposable consumer, run the fake edit/denial/recovery/branch/security matrix against an exact candidate SHA, and prove no real model endpoint or credential was available to that path.
4. **Handoff:** run zero-prompt Copilot startup, produce a redacted scenario report with run/PR/artifact references, document safe rerun/cleanup and the separate real-prompt smoke policy, and leave the sofa PR for Kevin.

## Acceptance

- [ ] **01.1-A:** The fast suite drives an allowed fake-ACP edit through the actual worker, verifier, and publisher boundaries. The candidate and trusted check share one digest; exactly one draft PR is created in the fake GitHub state. The peer's measured real-provider requests are zero.
- [ ] **01.1-B:** Table-driven cross-stage cases reject non-Ready, edited-after-Ready, ambiguous/foreign, malformed, changed-base, no-change, invalid recipe, and completed/duplicate work before publication. Assert prompt/dispatch counts explicitly rather than inferring zero from quiet logs.
- [ ] **01.1-C:** Named faults cover admission-before-dispatch, cancellation during an ACP turn, accepted-checkpoint loss/expiry/provenance, verification failure, publication response/lookup loss, and branch conflicts. Recovery preserves the original limits, rejects stale owners, never overwrites human work, and never creates a second PR.
- [ ] **01.1-D:** Workflow-contract and independent pin checks catch a deliberately broken numeric input conversion, inconsistent SHA, wrong image architecture or package digest, missing required permission boundary, broken artifact handoff, and a recovered-publication condition that silently skips after skipped execution. The hosted suite proves the key scheduler path; static assertions alone do not satisfy it.
- [ ] **01.1-E:** At least one hosted run in `sofa-disposable` uses the fake ACP peer inside the restricted container to make a bounded change, passes secretless verification, and opens exactly one draft PR. Its evidence identifies `fake-acp`, and the job has no real provider credential, provider permission, or model endpoint access. A completed redelivery skips execution and creates no second PR.
- [ ] **01.1-F:** Hosted fault cases show a retained candidate is reverified and published after one controlled interruption/failure, while an unexpected branch head is not moved and receives no PR. Correlate run IDs, checkpoint producer, ledger generation/counters, branch SHA, and PR identity. Keep the full fault matrix local.
- [ ] **01.1-G:** Inert-sentinel checks and credential/job inspection show the tested worker cannot read Project, state, App, or publisher credentials; logs and retained artifacts contain no injected sentinel values. The test coordinator cannot run from an untrusted PR event, and a forged issue/config cannot enable the fake profile in a normal consumer.
- [ ] **01.1-H:** A zero-prompt hosted probe starts the pinned real Copilot package and completes ACP initialization/session setup without a prompt. Report package/image/runner versions and classify failure safely. A separate one-prompt smoke remains optional and explicitly budgeted; its absence does not weaken the model-free suite's claim.
- [ ] **01.1-I:** The suite emits a versioned, redacted report for every scenario, with exact candidate SHA, commands, hosted run/PR/artifact links, measured fake prompt/provider-request counts, duration, and owned cleanup state. Successful repeat runs are idempotent. Operator instructions reproduce and safely recover the canary without changing sofa merge authority.

## Exclusions and later handoff

Do **not** create and delete a GitHub repository for every PR. Provisioning and deletion need broader repository-administration rights and a cleanup service that survives cancelled jobs. A periodic fresh-repository installation rehearsal belongs in [10 — Release readiness](10-release-readiness.md) after this stable-tenant suite works, with explicit owner-approved scope and teardown evidence. Standard runners in public repositories are currently free; private runners and artifact storage still require a configured usage budget. [GitHub Actions billing](https://docs.github.com/en/billing/concepts/product-billing/github-actions), [repository administration API](https://docs.github.com/en/rest/repos/repos)

Exclude new agent harnesses, System One routing, lifecycle boards, independent specialist gates, memory, watches, and automatic merge. The test coordinator is test infrastructure, not a production work-source or central sofa controller.

Write `docs/milestones/evidence/01.1-e2e-regression-harness.md` under the shared evidence contract. Distinguish simulated failures, hosted fake-ACP observations, zero-prompt Copilot compatibility, and any optional real-prompt observation. Leave the sofa PR draft and unmerged; disposable setup and test PRs may be managed under Kevin's existing disposable-only authorization.
